# G-Helper Omen v0.4.0

### What's New
* **AMD Ryzen Undervolting**: Added native support for Ryzen SMU undervolting via the PawnIO kernel interface. You can now tweak and undervolt AMD CPUs directly from G-Helper.
* **Omen Lighting Enhancements**: Improved integration and controls for Omen per-key and 4-zone lighting services.
* **WMI Fan Controller Updates**: Restructured the WMI fan control logic for better handling of fan speeds and transitions, including improved V1 fallback compatibility.
* **UI & Settings Tweaks**: Updated fans and extra settings menus to wire up the new hardware capabilities seamlessly.

### Fixes
* **Hardware Detection Hygiene**: Improved startup validation and detection sequences to avoid ghost hardware locks.
* **Power Limits**: Better power limit sanity-checking to align with HP WMI's native behaviors.
* Fixed an issue with dynamic lighting URIs and lighting forms.

**Note:** As always, some features may vary by hardware generation. Please open an issue if your model behaves unexpectedly.
